CERTICHAIN - CODE TITANS
Blockchain-Based Certificate Verification Prototype

PROJECT CONTENTS
- index.html: Self-contained interactive frontend prototype.

HOW TO RUN ON WINDOWS, macOS, OR LINUX
1. Extract this ZIP file.
2. Open the extracted folder.
3. Double-click index.html.
4. If asked, choose a modern browser such as Microsoft Edge, Google Chrome, Firefox, or Safari.

HOW TO SHARE WITH OTHER LAPTOPS
- Send the ZIP file to teammates or judges.
- They should extract it and open index.html in a modern browser.
- No programming environment is required to run this local demo.

IMPORTANT LIMITATIONS
This package contains a frontend demonstration. Certificate records/blockchain actions are simulated in the browser; it is not connected to a deployed blockchain, production backend, or secure institutional database. Do not use real student personal data or treat the demo result as official certificate verification.

TO PUBLISH ONLINE
Upload the extracted project folder to a static hosting provider that supports HTML sites. The entry file is index.html. Internet hosting may require creating an account.
